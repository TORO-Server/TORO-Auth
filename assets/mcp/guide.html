接続先

AI クライアントの接続設定に、次の URL を登録してください。OAuth の設定は自動で見つかります。

{{MCP_URL}}/

つなぎ方

その 1　Claude.ai

  1. [設定] → [コネクタ] (または [カスタムコネクタを追加]) を開きます。
  2. コネクタ名に TORO Server AI Gateway と入力します。
  3. サーバー URL に {{MCP_URL}}/ を入力し、[追加] を押します。
  4. 開いた「連携の許可」の画面で承認すると、7 種類のツールが使えるようになります (未ログインなら先に Discord でログインします)。

その 2　ChatGPT

  1. [設定] → [プラグイン] → [カスタム MCP サーバーを追加] を開きます。
  2. 名前に TORO Server、接続形式に [サーバー URL] を選びます。
  3. サーバー URL に {{MCP_URL}}/ を入力します (OAuth は自動で判別されます)。
  4. 同意のチェックを入れて [プラグインとして作成] を押し、開いた「連携の許可」の画面で承認します。

その 3　Google Gemini

  1. [連携アプリ] → [カスタムアプリを作成] を開きます。
  2. 接続先の URL に {{MCP_URL}}/ を入力し、Google の確認へ進みます。
  3. 開いた「連携の許可」の画面で承認すると、7 種類のアクションが同期されます。
  4. チャットの中で @Toro Server Ai Gateway を呼び出して使います。

その 4　手元のアプリ (Claude Desktop / Cursor など)

設定ファイル (claude_desktop_config.json など) に次の定義を足します。

{
  "mcpServers": {
    "toro-server": {
      "url": "{{MCP_URL}}/"
    }
  }
}

ツール

  • wiki_list_pagesWiki の原稿の一覧を見るだれでも
  • wiki_get_pageWiki の原稿と Git SHA を読むだれでも
  • wiki_searchWiki の全文を語句で探すだれでも
  • wiki_save_pageWiki の原稿を保存し、GitHub にコミットするメンバー
  • server_get_statusMinecraft サーバーの接続人数や状態を見るだれでも
  • server_get_infoTORO サーバーの各サービスの案内を見るだれでも
  • auth_get_identity呼び出し元の身元と編集の権限を確かめるログイン時
