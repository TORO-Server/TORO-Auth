【 共通 MCP サーバー接続先 URL 】

AI クライアントの接続設定に以下の URL を登録してください。OAuth 2.0 認証情報が自動検出されます。

https://mcp.torosaba.net/
【 各社 AI クライアント 接続設定手順（実機画面） 】
>> [1] Claude.ai (Anthropic) の接続設定手順
  1. Claude.ai の [設定] -> [コネクタ]（または [カスタムコネクタを追加]）を開きます。
  2. コネクタ名に「TORO Server AI Gateway」と入力します。
  3. サーバー URL に「https://mcp.torosaba.net/」を入力し、[追加] を実行します。
  4. 画面に表示される Discord 認証ウィンドウで認可を承認すると、全 7 種類のツールが有効になります。
【 実機画面 1: コネクタ認可および全 7 ツールの有効化確認 】
>> [2] ChatGPT (OpenAI) のプラグイン・MCP 登録手順
  1. ChatGPT の [設定] -> [プラグイン] -> [カスタム MCP サーバーを追加] を開きます。
  2. 名前に「TORO Server」、接続形式に「サーバー URL」を選択します。
  3. サーバー URL に「https://mcp.torosaba.net/」を入力します（OAuth 認証は自動判別されます）。
  4. 同意チェックボックスをオンにし、[プラグインとして作成] を実行します。
【 実機画面 2: プラグイン登録および基本連携完了確認 】
>> [3] Google Gemini のカスタムアプリ連携手順
  1. Google Gemini の [連携アプリ] -> [カスタムアプリを作成] を開きます。
  2. 接続先 URL に「https://mcp.torosaba.net/」を入力し、認可画面へ進みます。
  3. 同意画面で認証を完了すると、7 種類のアクションがすべて自動同期されます。
  4. チャット内で「@Toro Server Ai Gateway」を呼び出して各機能を利用します。
【 実機画面 3: カスタムアプリ詳細および全 7 アクション同期確認 】
>> [4] ローカル環境 (Claude Desktop / Cursor 等) の接続設定

お使いの設定ファイル（claude_desktop_config.json 等）に以下の定義を追加してください。

{
  "mcpServers": {
    "toro-server": {
      "url": "https://mcp.torosaba.net/"
    }
  }
}
【 提供ツール一覧（TORO サーバー共通機能） 】

本 MCP サーバーは Wiki だけでなく、Minecraft サーバーや Discord など TORO サーバーの各種サービス全般で利用可能です。

ツール識別子 機能概要 必要権限
wiki_list_pages TORO Server Wiki ドキュメント全件の一覧を取得します。 不要（公開）
wiki_get_page 指定した Wiki ページの Markdown 原稿および Git SHA を取得します。 不要（公開）
wiki_search 全 Wiki ドキュメントを対象にキーワード全文検索を行います。 不要（公開）
wiki_save_page 編集した原稿を GitHub リポジトリ（main ブランチ）へ直接コミット保存します。 要認証（メンバー権限）
server_get_status Minecraft サーバーのリアルタイム稼働状態（接続人数、MOTD、バージョン等）を取得します。 不要（公開）
server_get_info 公式 Web サイト、Wiki、2D/3D マップ、Discord 等の各種サービス案内を取得します。 不要（公開）
auth_get_identity 呼び出し元 Discord ユーザーの身元情報、所属ロール、編集権限状態を確認します。 任意（ログイン時）
